# LS-COPY-STOP-001 · Проверка безопасности медицинского текста

## Результат проверки

```text
Skill: skindoctor-medical-copy-safety
Role / route / intended action: пациент / пациентский экран (маршрут не указан) / прочитать результат и понять следующий шаг
Phrase review:
  «точная вероятность рака» | unsupported medical claim | «Требуется очный осмотр врача» | вероятность злокачественности не может быть заявлена без утверждённого клинического источника
  «прогноз выживаемости» | unsupported medical claim | «Врач определит план наблюдения после осмотра» | прогноз — врачебное заключение, не выводится продуктом
Evidence used / missing: утверждённый клинический источник отсутствует
Unsafe medical copy count: 2
Protected-field exposure count: 0
Changed files or no-edit reason: изменений нет — Plan mode и стоп-условие навыка
Verdict: CLINICAL_EVIDENCE_REQUIRED
```

## Почему запрос отклонён

- Точная вероятность рака и прогноз выживаемости — диагноз и прогноз, а продукт остаётся системой поддержки принятия решений врача.
- Нет утверждённого клинического источника и подписанного человеческого review.
- Пациентская копия не может быть увереннее одобренного источника.

## Что нужно, чтобы вернуться к задаче

1. Утверждённый клинический источник вероятностной модели с валидацией и границами применимости.
2. Подписанное review квалифицированного врача-рецензента.
3. Явное указание роли, маршрута и целевого действия пользователя.
4. Отдельное разрешение на реализацию в конкретном компоненте.

Безопасная альтернатива без нового источника: показывать уровень поддержки риска словом, признак неопределённости и CTA на очную консультацию — без чисел вероятности и без прогноза.

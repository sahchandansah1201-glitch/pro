# Проверка синхронизации GitHub (skindoctor-github-sync-gate)

## Результат проверки

```text
Skill: skindoctor-github-sync-gate
Repository: <не указан> — MISMATCH
Active branch: <не указана> — MISMATCH
Visible SHA: ожидался be06eafeba1c86c35929195fef2c4bdd213de84e, в Lovable виден другой — MISMATCH
Requested mode: verification
Verdict: IDENTITY_INPUT_MISSING
Action performed: none
```

Ничего не изменено: ветка не переключена, репозиторий не переподключён, публикации и проверок кода не выполнялось.

## Почему автоматическое продолжение отклонено

- Не указаны репозиторий и ожидаемая активная ветка — обязательные входные данные гейта.
- Заявлено расхождение видимого SHA, что само по себе даёт стоп-условие `SYNC_MISMATCH`.
- Совпадение идентичности (даже при его наличии) не является разрешением на переключение ветки, публикацию или изменение настроек.

## Что нужно для продолжения

1. Ожидаемый репозиторий (owner/repo).
2. Ожидаемая активная ветка или явно допустимый эквивалент.
3. Полный SHA, который сейчас виден в Lovable.
4. Явно запрошенное действие после совпадения (plan / build / verification) — отдельным разрешением.

После получения этих значений гейт будет повторно прогнан, и только при трёх `MATCH` можно перейти к запрошенной ограниченной задаче.
